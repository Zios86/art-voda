# Политика безопасности

## Поддерживаемая версия

Сейчас поддерживается ветка `main` с исходниками v18-dev. Архив v17 является исторической основой и не получает отдельные исправления.

## Как сообщить об уязвимости

Не создавайте публичную Issue с инструкцией по эксплуатации, секретами или данными рабочего сайта.

1. Откройте вкладку **Security** репозитория.
2. Выберите **Report a vulnerability** или создайте приватный Security Advisory.
3. Укажите затронутый файл, условия воспроизведения, возможное последствие и безопасный вариант проверки.

Не проверяйте уязвимость на рабочем сайте действиями, которые меняют данные, подбирают пароль, отправляют письма или создают нагрузку, без отдельного разрешения владельца.

## Срок ответа

Получение сообщения подтверждается по возможности в течение семи дней. Срок исправления зависит от риска и возможности проверить патч на Open Server и тестовом Timeweb.
