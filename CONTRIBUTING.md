# Как вносить изменения

## Перед началом

1. Прочитайте `AGENTS.md`, `PROJECT_STATUS.md` и `docs/00_START_HERE.md`.
2. Создайте отдельную ветку от актуальной `main`.
3. Не добавляйте `private/config.php`, секреты, backup, логи и пользовательские uploads.

## Правила

- одна задача — один связный pull request;
- изменяющие PHP-операции требуют авторизации, CSRF и проверки входных данных;
- опасные операции требуют повторного пароля с rate limit;
- SQL выполняется подготовленными PDO-запросами;
- inline JavaScript запрещён строгой CSP админки;
- не добавляйте статусы автоматов, даты обслуживания и способы оплаты;
- не придумывайте данные точек;
- обновляйте связанную документацию.

## Проверка

Дождитесь зелёного workflow `Security checks`. Для PHP/MySQL, сессий, загрузок и `.htaccess` дополнительно выполните smoke-тест на Windows/Open Server. В pull request явно перечислите всё, что не проверялось.
