# Карта файлов

Это ожидаемая карта v17. Claude обязан заменить предположения фактическими путями после осмотра исходников.

| Путь | Назначение | Правило |
|---|---|---|
| `public_html/` | корень сайта | единственный web root |
| `public_html/index.php` | главная страница | число точек не хранить вручную |
| `public_html/api/` | публичный API | экранирование, корректный JSON, кеш |
| `public_html/admin/` | административные страницы | вход + CSRF для изменений |
| `public_html/admin/batch.php` | пакетные изменения | менять только фактически изменённые ID |
| `public_html/css/` | стили | избегать новых дублей |
| `public_html/js/` | клиентская логика | без inline JS при строгой CSP |
| `public_html/js/offline.js` | офлайн-интерфейс | удалить статусы автоматов |
| `public_html/offline.html` | офлайн-страница | версии ресурсов равны `sw.js` |
| `public_html/sw.js` | Service Worker | не кешировать `/admin` и секретные ответы |
| `public_html/data/kiosks.json` | резервные данные | генерировать из БД автоматически |
| `public_html/uploads/` или аналог | фотографии | запрет исполнения PHP |
| `public_html/img/brand-logo-artesian.png` | настоящий логотип | не заменять генерацией |
| `public_html/img/index.php` | старый архивный код | не использовать и не публиковать |
| `public_html/offer.php` | публичный текст | убрать способы оплаты |
| `private/` | серверные файлы | никогда не публиковать |
| `private/config.php` | секреты окружения | не коммитить и не выводить |
| `private/config.php.example` | шаблон конфигурации | только безопасные примеры |
| `private/schema.sql` | чистая схема БД | источник для новой установки |
| `private/migrate_v15_to_v16.sql` | обновление старой БД | не запускать на чистой схеме |
| `release/` | готовые ZIP | не редактировать вручную |
| `PROJECT_MAP.md` | прежняя карта проекта | объединить с этим документом |
| `AGENTS.md` | правила прежнего агента | не допускать конфликта с `CLAUDE.md` |

После сверки добавить точные точки входа, имена общих PHP-файлов, таблиц, build-скрипта и runtime-каталогов.
