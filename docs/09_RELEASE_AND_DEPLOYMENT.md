# Релиз и публикация

## Правило

Релиз создаётся официальным build-скриптом по белому списку. Нельзя копировать весь рабочий `public_html` и нельзя исправлять готовый ZIP вручную.

Команда сборки кандидата:

```bash
bash release/build_release.sh v18-rc1 2026-09-01
```

Белый список находится в `release/RELEASE_MANIFEST.txt`. Результат и отдельная контрольная сумма создаются в `dist/`.

## Перед сборкой

1. Все блокеры закрыты или явно согласованы.
2. Выполнен smoke-тест Open Server.
3. Обновлены schema и миграции.
4. Нет секретов, дампов, runtime, backup и старых файлов.
5. Обновлены `PROJECT_STATUS.md`, release notes и QA.
6. Версии PWA-ресурсов синхронизированы.

## Состав релиза

Ожидаются только публичные файлы, необходимые защищённые серверные файлы, schema/migrations и безопасный example-конфиг. Документация для разработчика может не публиковаться в web root.

## Проверка ZIP

- архив открывается без ошибок;
- список файлов совпадает с белым списком;
- нет `private/config.php`, логов, backup, `.git`, старого `img/index.php`;
- рассчитана SHA-256;
- выполняется тестовая распаковка в пустой каталог.

## Timeweb

1. Сделать полный backup текущего сайта и БД.
2. Развернуть на тестовом поддомене.
3. Выполнить миграцию только для фактической старой версии.
4. Запустить smoke-тест.
5. Проверить PHP-лог, почту, права каталогов, карту, загрузку фото и cron, если он есть.
6. Только после одобрения владельца переносить на production.
7. Иметь понятный план отката: предыдущий ZIP + backup БД + фотографии.

## GitHub

- Основной репозиторий исходников: `https://github.com/Zios86/art-voda`.
- Репозиторий публичный: реальные секреты, runtime, backup, логи и пользовательские загрузки запрещены.
- GitHub Pages не выполняет PHP и MySQL, поэтому не используется как доказательство работоспособности проекта.
- Полноценная проверка выполняется на Windows/Open Server и тестовом поддомене Timeweb.
- Если позже настраивается автоматическая доставка на Timeweb, реквизиты размещаются только в GitHub Actions Secrets и ограничиваются тестовым окружением.
