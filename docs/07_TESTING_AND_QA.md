# Тестирование и QA

## Минимум для каждой правки

- синтаксис всех изменённых PHP-файлов: `php -l файл.php`;
- синтаксис изменённых JS-файлов: `node --check файл.js`;
- валидность JSON;
- проверка shell/build-скрипта;
- успешный сценарий и ожидаемая ошибка;
- отсутствие ошибок в консоли и PHP-логе.

## Smoke-тест публичной части

- главная открывается по HTTPS;
- меню, ссылки и мобильная версия работают;
- API возвращает корректный JSON;
- карта загружает реальные точки;
- поиск и карточка точки работают;
- нет статусов, дат обслуживания и способов оплаты;
- форма обращения показывает успех/ошибку и не теряет данные;
- офлайн-страница имеет стили и скрипты после перезагрузки без сети.

## Smoke-тест админки

- неверный пароль ограничивается;
- успешный вход создаёт одну активную сессию;
- CSRF-блокировка работает;
- создание, изменение и откат карточки записываются в историю;
- пакетная карта не пишет изменения для неподвижных точек;
- CSV-preview ничего не меняет;
- CSV с повторным номером отклоняется;
- опасная операция требует пароль и ограничивает перебор;
- неудачное сохранение сохраняет браузерный черновик;
- backup сравнивается и восстанавливается на тестовой базе;
- удаление фото учитывает версии и backup.

## Браузеры и размеры

Проверить Chrome/Edge на Windows: 320, 375, 768, 1024 и 1440 px. Для PWA обязательно DevTools → Application → Service Workers/Cache Storage.

## Отчёт

Создавать `QA_RESULTS_YYYY-MM-DD-vNN.md`: окружение, команды, пройдено, не пройдено, что не проверялось и ссылки на дефекты. «Синтаксис прошёл» не заменяет запуск сайта.
