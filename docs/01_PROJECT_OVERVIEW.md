# Обзор проекта

«Киосквода» — PHP-сайт сети автоматов артезианской воды. Посетитель видит информацию и карту точек. Администратор управляет карточками, координатами, фотографиями, импортом, резервными копиями и качеством данных.

## Цели

- показывать посетителю только подтверждённые сведения;
- позволять владельцу безопасно обновлять список автоматов;
- работать на обычном хостинге Timeweb;
- иметь локальную среду Windows/Open Server;
- оставаться понятным без сложной серверной инфраструктуры.

## Источники истины

1. MySQL — текущие рабочие данные.
2. Исходники рабочего каталога — код.
3. Белый список сборки — состав публикации.
4. Release notes и QA-файл — описание конкретного выпуска.
5. ZIP в `release/` — неизменяемый результат сборки, но не место разработки.

## Пользовательские роли

- посетитель: читает страницы, ищет точку, открывает карту, отправляет обращение;
- администратор: входит в закрытую панель и изменяет данные;
- владелец проекта: утверждает бизнес-данные, публичные формулировки и публикацию.

## Что не является функцией проекта

Статусы автоматов, даты обслуживания и способы оплаты не должны присутствовать в публичном интерфейсе или админской модели без нового прямого решения владельца.
