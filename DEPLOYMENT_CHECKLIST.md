# Проверка кандидата v18 для Timeweb

## До загрузки

- [ ] Скачать резервные копии сайта и базы в панели Timeweb.
- [ ] Использовать только `public_html` из релиза, не смешивать его со старыми файлами.
- [ ] Разместить `private` рядом с `public_html` по инструкции `TIMEWEB_INSTALL.md`.
- [ ] Выбрать PHP 8.4 или 8.5 в панели Timeweb.
- [ ] Убедиться, что расширения PHP `fileinfo` и `gd` включены.
- [ ] Убедиться, что включено расширение PHP `zip` (`ZipArchive`).
- [ ] Создать MySQL-базу и импортировать `private/schema.sql`.
- [ ] Для существующей базы после полного backup выполнить `private/migrate_v18_audit.sql`.
- [ ] Создать `private/config.php`, указать базу, хеш пароля, случайный `audit_key` и почтовые адреса.
- [ ] Установить права `700` для `private` и `600` для `private/config.php`.
- [ ] Ограничить ключ Яндекс.Карт доменом и нужными API в кабинете Яндекса.
- [ ] Дополнительно запаролить `/admin` через панель Timeweb.

## Проверка после загрузки

- [ ] HTTP и `www` перенаправляются на основной HTTPS-адрес без `www`.
- [ ] Архивы, старые PHP и `/new/` недоступны.
- [ ] До согласия нет запросов к Метрике, Яндекс.Картам и Rutube.
- [ ] После отказа от аналитики новые запросы Метрики прекращаются.
- [ ] Карта и главная показывают одинаковое количество точек из базы, поиск работает.
- [ ] «Рядом со мной» запрашивает разрешение и показывает ближайшие карточки.
- [ ] Поиск по введённому адресу находит ближайшие точки и фирменные метки.
- [ ] `/admin/` требует вход; тестовую точку можно добавить и переместить.
- [ ] После 8 неверных входов учётная запись временно блокируется; настоящий пароль при этом не проверяется.
- [ ] Выход из панели работает только кнопкой POST, а после 30 минут бездействия требуется новый вход.
- [ ] В кабинете отображаются правильное число точек, журнал изменений и CSV.
- [ ] Изменение в панели появляется на публичной карте не позднее минуты.
- [ ] После изменения обновился `public_html/data/kiosks.json`.
- [ ] Полный ZIP-backup содержит базу, фото и контрольные суммы.
- [ ] Неудачное сохранение не удаляет черновик; восстановление обновляет карту и preview.
- [ ] На Android/Chrome появляется установка PWA, на iPhone показана инструкция.
- [ ] После первого посещения офлайн-страница открывает сохранённый список адресов.
- [ ] Форма принимает только POST, ограничивает частые запросы и доставляет тестовое письмо.
- [ ] В DevTools нет ошибок CSP; карта, поиск адреса, Rutube и Метрика после согласия загружаются.
- [ ] `/api/kiosks.php` отвечает JSON, ETag и 304 работают, частые запросы получают 429.
- [ ] SPF, DKIM и DMARC почтового домена настроены.
- [ ] Координаты автоматов у Авиаторов Балтики, 13 и 17 подтверждены владельцем.
- [ ] Карта, Rutube, меню и мобильные размеры проверены вручную.

## Быстрый откат

В разделе «Резервные копии» Timeweb восстановить предыдущую копию файлов и базы. Старые PHP и архивы нельзя оставлять в публичном каталоге.
