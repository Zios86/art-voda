# «Киосквода»

Сайт сети автоматов артезианской воды: публичные страницы и карта точек, PHP API, административная панель, импорт CSV, история изменений, фотографии и резервные копии.

## Текущее состояние

- Версия исходников: v18-dev на основе v17 Admin Suite.
- Окружение: Apache, PHP 8.4, MySQL 8.0+; в инструкции Open Server используется модуль MySQL 8.4.
- Рабочая ОС разработчика: Windows 10/11 с Open Server Panel.
- Хостинг: обычный Timeweb.
- Статус: исправления аудита безопасности добавлены в исходники; перед рабочим развёртыванием обязателен smoke-тест из [PROJECT_STATUS.md](PROJECT_STATUS.md).

## Быстрый старт

1. Прочитайте [CLAUDE.md](CLAUDE.md) и [PROJECT_STATUS.md](PROJECT_STATUS.md).
2. Для чистой установки импортируйте `private/schema.sql`.
3. Создайте `private/config.php` из `private/config.php.example` и заполните его локальными значениями.
4. Укажите `public_html` как корень сайта.
5. Следуйте инструкции [для Windows и Open Server](docs/08_LOCAL_WINDOWS.md).

Подробная установка на Timeweb описана в [TIMEWEB_INSTALL.md](TIMEWEB_INSTALL.md).

## Важно о GitHub Pages

GitHub Pages не выполняет PHP и не предоставляет MySQL. Поэтому этот репозиторий используется для хранения и сопровождения кода, а полноценная проверка проводится через Open Server или тестовый поддомен Timeweb.

## Безопасность

- Не добавляйте в Git `private/config.php`, резервные копии, логи и пользовательские загрузки.
- Не публикуйте пароли, хеш администратора, ключ аудита и почтовые настройки.
- Ключ клиентской карты виден браузеру по конструкции; для него обязательно ограничение разрешённых доменов в кабинете провайдера.
- Перед выпуском выполняйте проверки из [docs/07_TESTING_AND_QA.md](docs/07_TESTING_AND_QA.md).
- GitHub автоматически запускает проверку PHP/JS/JSON, Gitleaks и CodeQL для JavaScript.
