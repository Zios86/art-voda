# QA асимметричной сетки карточек

Дата: 8 октября 2026 года.

## Изменение

- публичная секция «Почему выбирают нас» использует четыре колонки на широком экране;
- первая карточка занимает две колонки и выделена цветом;
- остальные карточки имеют разные высоты и заполняют две соседние колонки без пустот;
- при ширине до 1100 пикселей используется две колонки;
- при ширине до 600 пикселей карточки идут одним последовательным столбцом.

## Автоматически проверено

- наличие `grid-auto-flow: dense`;
- двухколоночный размер первой карточки;
- разные размеры строк карточек;
- сброс masonry-параметров на телефоне;
- совпадение версии основных CSS с Service Worker;
- отсутствие ошибок форматирования Git diff.
- GitHub Actions: PHP/JS/JSON, проектные регрессии, сборка, MySQL 8.4, Gitleaks и CodeQL.

## Требует ручной проверки

- внешний вид в Chrome/Edge на ширинах 1440, 1024, 768 и 390 пикселей;
- отсутствие переполнения текста при реальном шрифте;
- hover-анимация и порядок чтения с клавиатуры;
- Open Server и тестовый поддомен Timeweb.

Статус: код готов к проверке в браузере; production-готовность не подтверждена.
