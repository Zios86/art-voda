# Киосквода v18-rc3 — кандидат для тестового развёртывания

Дата сборки: 8 октября 2026 года.

Это версия для Open Server и тестового поддомена Timeweb. На рабочий домен её нельзя устанавливать до прохождения `DEPLOYMENT_CHECKLIST.md`.

## Главное

- исправлен офлайн-режим и синхронизированы версии ресурсов;
- `kiosks.json` автоматически обновляется после изменения базы;
- количество точек на главной рассчитывается из БД;
- полный ZIP-backup включает базу, используемые фотографии и SHA-256;
- импорт и восстановление показывают точные отличия и полностью журналируются;
- черновик формы сохраняется до успешного ответа сервера;
- после восстановления черновика обновляются карта и предпросмотр;
- добавлены история корзины фотографий и восстановление файлов;
- добавлен понятный обезличенный журнал безопасности;
- пакетная операция показывает реально изменённые точки;
- добавлены автоматические PHP, JavaScript, JSON, MySQL, Gitleaks и CodeQL-проверки;
- блок «Почему выбирают нас» получил асимметричную CSS Grid-сетку, разные высоты карточек и первый акцентный блок на две колонки.
- карта поднята ближе к первому экрану, добавлен быстрый поиск адреса;
- удалён повторяющийся ценовой блок, добавлены FAQ и структурированные данные;
- публичные тексты больше не перечисляют конкретные способы оплаты.

## Обновление существующей базы

Перед заменой файлов скачайте полную копию базы и фотографий. Для базы v16/v17 один раз выполните:

```text
private/migrate_v18_audit.sql
```

Для чистой установки используйте только `private/schema.sql` — миграции поверх неё не запускаются.

## Не изменено по решению владельца

- статусы автоматов не добавляются в интерфейс;
- способы оплаты не указываются;
- даты обслуживания не добавляются;
- двухфакторная авторизация не внедряется.

## Статус проверки

GitHub Actions прошёл полностью, включая чистую MySQL 8.4. Open Server, Apache, браузер и тестовый Timeweb ещё обязательны.
