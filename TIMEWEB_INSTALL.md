# Установка на обычный виртуальный хостинг Timeweb

## 1. Файлы

1. Сделайте резервную копию действующего сайта.
2. Загрузите содержимое папки `public_html` в папку сайта `public_html`.
3. Папку `private` разместите рядом с `public_html`, а не внутри неё.
4. Переименуйте `private/config.php.example` в `private/config.php`.
5. Для папки `private` установите права `700`, для `private/config.php` — `600`. Она должна быть доступна PHP, но не из интернета.

Итоговая структура:

```text
папка-сайта/
├── private/
│   ├── config.php
│   └── schema.sql
└── public_html/
    ├── admin/
    ├── api/
    └── ...
```

## 2. PHP и база

1. В панели Timeweb откройте «Сайты → Мои сайты» и установите PHP 8.4 или 8.5.
   Убедитесь, что включены расширения `fileinfo`, `gd` и `zip`: они нужны для безопасной обработки фотографий и полной ZIP-копии.
2. В разделе «Базы данных» создайте MySQL-базу и пользователя.
3. Откройте phpMyAdmin, выберите созданную базу и импортируйте `private/schema.sql`.
4. Впишите имя базы, пользователя и пароль в `private/config.php`.

Если база уже была создана для версии v9, вместо повторного импорта `schema.sql` один раз выполните файл `private/migrate_v9_to_v10.sql`. Он добавит поля метро, ориентира и фотографии, не удаляя существующие автоматы.

При обновлении с версии v15 один раз выполните `private/migrate_v15_to_v16.sql`. Он добавит историю карточек и не изменит существующие автоматы.

При обновлении существующей базы v16/v17 до v18 после полной резервной копии один раз выполните `private/migrate_v18_audit.sql`. Для чистой базы из актуального `schema.sql` эта миграция не нужна.

## 3. Пароль администратора

По SSH выполните:

```bash
php -r "echo password_hash('ВАШ_СЛОЖНЫЙ_ПАРОЛЬ', PASSWORD_DEFAULT), PHP_EOL;"
```

Скопируйте результат в `private/config.php` вместо `PASTE_PASSWORD_HASH_HERE`.

Создайте отдельный случайный ключ журнала:

```bash
php -r "echo bin2hex(random_bytes(32)), PHP_EOL;"
```

Скопируйте его вместо `PASTE_64_RANDOM_HEX_HERE`. Не используйте пароль администратора как этот ключ.
Панель откроется по адресу `/admin/`.

Дополнительно включите в панели Timeweb паролирование папки `/admin` — это создаст второй уровень защиты.

В кабинете разработчика Яндекс ограничьте ключ Карт доменом `киоскводы.рф` и разрешите только используемые API. После установки удалите с сервера старые архивы, тестовые PHP-файлы и прежние копии сайта.

## 4. Как добавить автомат

1. Откройте `/admin/` и войдите.
2. Укажите номер, адрес и город/район.
3. Нажмите «Найти координаты по адресу».
4. Если точка неточная, перетащите метку или нажмите на нужное место карты.
5. Проверьте карточку предпросмотра и нажмите «Сохранить».

Можно дополнительно указать метро, ориентир и загрузить фотографию до 5 МБ. Карточка предпросмотра покажет результат до сохранения. Для массового обновления сначала скачайте CSV из админки, измените его и загрузите через блок «Импорт CSV». Перед каждым сохранением и импортом сервер создаёт закрытую резервную копию в `private/runtime/backups`.

Публичная карта обновляет данные не позднее чем через одну минуту.

В панели владельца также доступны последние изменения, импорт и выгрузка автоматов в CSV.

## 5. Установка сайта как приложения

PWA работает только по HTTPS. Убедитесь, что в Timeweb установлен SSL-сертификат и сайт открывается без предупреждений. После первой успешной загрузки совместимый браузер сможет показать кнопку «Установить» в нижней мобильной панели.

## 6. Форма обратной связи

Укажите `mail.recipient` и `mail.from` в `private/config.php`. Адрес `from` должен принадлежать настроенному на Timeweb домену. Для максимально надёжной доставки позднее можно подключить SMTP. Не храните пароль почты внутри `public_html`.
