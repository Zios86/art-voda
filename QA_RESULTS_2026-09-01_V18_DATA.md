# QA v18-dev — данные, offline, backup и админка

Дата: 1 сентября 2026 года.

## Реализовано

- синхронизация версий `offline.html` и `sw.js`;
- автоматическая генерация `data/kiosks.json` после всех изменяющих операций;
- динамическое количество точек на главной;
- полный ZIP-backup базы и используемых фотографий;
- сортировка ротации backup по `filemtime`;
- полный построчный аудит импорта и восстановления;
- сохранность черновика до успешного ответа и обновление карты/preview;
- восстановление фото из 30-дневной корзины;
- читаемый обезличенный журнал безопасности;
- точный список результатов пакетной операции;
- подробное сравнение перед импортом и восстановлением;
- автоматические тесты `tests/project_checks.php` и `tests/database_checks.php` в GitHub Actions;
- отдельный CI-job поднимает чистую MySQL 8.4, импортирует `schema.sql` и проверяет транзакционную запись версии и аудита.

## Проверено в текущей среде

- синтаксис всех JavaScript-файлов: пройден `node --check`;
- JSON `public_html/data/kiosks.json` и `manifest.webmanifest`: разобран без ошибок;
- статический поиск подтвердил отсутствие старых версий offline CSS/JS и вручную заданного `136`.

## Не проверено

- PHP lint и `tests/project_checks.php`: PHP CLI в текущей среде отсутствует;
- миграция `private/migrate_v18_audit.sql` на MySQL;
- запись атомарного JSON веб-пользователем;
- создание ZIP через `ZipArchive`;
- полный браузерный сценарий черновика, карты, импорта, восстановления и фото;
- Open Server и тестовый Timeweb.

Статус: **реализовано, не готово к публикации до smoke-тестов**.
